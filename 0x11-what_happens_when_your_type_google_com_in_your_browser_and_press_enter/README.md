# Blog Post: What Happens When You Type www.google.com and Press ENTER?

In this blog post, we will explore the series of events that occur when you type "www.google.com" and press ENTER. The key concepts covered include:
 
1. DNS request
2. TCP/IP
3. Firewall
4. HTTPS/SSL
5. Load-balancer
6. Web server
7. Application server
8. Database

# Overview
Events that take place when you enter a URL in your browser involve:
	DNS Request: Translating the domain name to IP address.
	TCP/IP: Establishing a connection between your device and the web server
	Firewall: Ensuring secure communication by filtering incoming and outgoing traffic.
	HTTPS/SSL: Encrypting data transfer for security.
	Load Balancer: Distributing traffic across multiple servers to optimize performance and ensure reliability
	Web Server: Processing the bussiness logic and dynamic content.
	Database: Storing and retrieving data needed for the web application
